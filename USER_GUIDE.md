# Using EchoLab

[简体中文](USER_GUIDE.zh-CN.md)

1. Ask the maintainer to install dependencies and prepare learning content.
2. Start `start.bat` on Windows or `start.command` on macOS. Keep its window open.
3. Open http://localhost:8777/library.html and choose an episode.
4. Choose **English** or **中文** in the top bar. This changes controls, not subtitle content.
5. Click a subtitle to play it. Use sentence loop, pause after sentence and slower playback to practise shadowing.
6. Open Words or Chunks to review expressions and play their original context. Use ☆ to save favourites.

Progress and favourites stay in this browser. To use a phone on the same Wi-Fi, open the computer's LAN address shown in the server window instead of `localhost`.

To add content, open `/setup` and install the bookmark. With the server running, click it on a supported video page. Processing may take time and can incur the maintainer's configured LLM API costs.
