# EchoLab · 视频转英语学习材料流水线

一条命令,把任意英文视频变成精读级学习材料:语义群对齐的双语字幕、IPA 音标、
六类知识点卡片(带考级标签),再配一个为「影子跟读 / 回音练习法」设计的播放器。

设计目标是**家人自己就能用**——加视频、学、收藏,全程不需要你在场。

---

## 一、它做了什么

```
视频 ─▶ 音频 ─▶ 语音识别(词级时间戳)─▶ 语义群切分 ─▶ 翻译 ─▶ IPA
                                                        └─▶ 知识点卡片 ─▶ 校验 ─▶ data.json
```

关键点在**语义群切分**:参考产品是作者手工把字幕截成完整语义群(这是三个月里最贵的
那部分工作),这里改由模型按语义切、再用词级时间戳映射回时间轴,几秒钟完成。

另外两个刻意的工程决策:

- **模型输出的是词的下标,不是重写后的文本。** 让模型改写文本就无法可靠对回时间轴了
  (会漏词、改标点、合并缩写);输出下标则可以被程序严格校验和自动修复,时间轴永远准。
- **每张卡片都要回原文验证才留下。** 模型偶尔会"想起"一个原文没有的表达,
  而学习工具里出现凭空捏造的知识点是不可接受的。校验做了词干还原,
  所以 `take off` 能对上原文的 `took it off`,但 `break the ice` 这种没出现过的会被剔除。

## 三、正式使用

### 1. 装环境(一次性)

```bash
pip install -r requirements.txt
```

**两个外部程序,都不是硬性必需:**

| 程序 | 缺了会怎样 | 建议 |
|---|---|---|
| ffmpeg | 不影响。识别会改用内置解码器(PyAV)直接读原文件,只是没有封面图 | 装了更稳,能处理更多冷门格式 |
| espeak-ng | 不生成 IPA 音标,其它功能照常;`demo.py` 无法合成演示音频 | 想要音标就装 |

**Windows 最省事的装法(会自动配好 PATH):**

```powershell
winget install Gyan.FFmpeg
winget install eSpeak-NG.eSpeak-NG
```

装完**必须关掉命令行窗口重新开一个**,PATH 才会生效。

**手动配 PATH(没有 winget 或想装绿色版时):**

1. 把解压出来的目录记牢,比如 ffmpeg 是 `C:\ffmpeg\bin`(这个目录里要能看到 `ffmpeg.exe`)
2. 按 `Win + S` 搜「环境变量」→ 打开「编辑系统环境变量」→ 点「环境变量」按钮
3. 在上半部分「用户变量」里选中 `Path` → 「编辑」→「新建」→ 粘贴那个目录 → 一路确定
4. **关掉所有命令行窗口,重新打开一个**,输入 `ffmpeg -version` 验证

**其实也可以完全不碰 PATH:** 程序会自己去几个常见安装位置找
(`C:\Program Files\eSpeak NG\`、`C:\ffmpeg\bin\`、winget 的 Links 目录、
scoop 的 shims 等)。另外 `pip install imageio-ffmpeg` 会装一个自带的 ffmpeg 二进制,
程序也认——这是最省事的一条路,一条 pip 命令解决,不用改任何系统设置。

跑 `python process.py` 时开头会打印环境自检,告诉你这两个到底找到没有。

### 2. 填 API Key

```bash
cp .env.example .env      # 然后编辑 .env,填入 DeepSeek 或 Kimi 的 key
```

### 3. 处理视频

```bash
python3 process.py 我的视频.mp4 --title "第1期 · 咖啡店点单"
python3 serve.py
```

## 四、成本

| 环节 | 花费 |
|---|---|
| 语音识别 | **0**(本机跑,模型首次自动下载) |
| IPA 音标 | **0**(本机 espeak-ng) |
| 单词发音 | **0**(浏览器自带朗读) |
| 难度/时长/语速 | **0**(纯计算) |
| 语义群切分 + 翻译 + 卡片 | 走 API,一期 5 分钟视频约几分钱 |

省钱的三个设计:

1. **结果按内容哈希缓存**,同一个视频重跑不会二次付费(`--no-cache` 可关闭);
2. 默认用 deepseek-chat(单价最低那档),`--llm kimi` 可切换;
3. 每次运行结束打印 token 用量和估算费用,心里有数。

只想要字幕不要卡片,加 `--no-cards`,费用再降一半左右。

## 四点五、从网址取素材(实验中)

除了本地文件,也可以直接给一个网址:

```bash
python fetch.py <网址>              # 先分析:看看里面有什么,不下载
python fetch.py <网址> --download   # 确认后再下
python process.py --url <网址> --title "第1期"   # 取素材并直接加工
```

支持媒体直链、播客订阅源、页面里暴露了地址的网页、HLS 流四类;
再往下(播放器运行时动态取址的站点)会提示你自行安装 yt-dlp 兜底。

**推荐用播客订阅源**:enclosure 本来就是给客户端下载的,来源正当、地址稳定,
而且两个人自然对话的语料恰好最适合影子跟读。

只取回公开可访问的地址,不绕过付费墙、登录态或 DRM;
目标网站的服务条款与内容版权由使用者自行负责。细节见 `docs/在线视频解析-探索笔记.md`。

## 五、常用参数

```
--title      这一期的标题
--llm        deepseek(默认)| kimi
--asr-model  tiny.en / base.en / small.en(默认)/ medium.en   越大越准越慢
--no-cards   只做字幕,跳过知识点卡片
--no-cache   不用缓存,强制重新调用模型
--keep-media 不复制视频进 library(省磁盘,但视频不能挪位置)
```

机器慢就用 `--asr-model base.en`,追求准确度用 `medium.en`。

## 六、关于准确率(请如实告知使用者)

vlog 是自然口语,有背景音和口音,**语音识别准确率通常在 85-95%**,
语义群切分和翻译也会有瑕疵。这是这类技术当前的正常水平,不是没做好。

工具为此内置了校对线索:`data.json` 的 `review.low_confidence_words` 里
列出了识别把握较低的词,校对时只看这些就行,不必通读全文。
`review.dropped_cards` 记录了被判定为原文中不存在、已剔除的词条。

---

## 七、考级标签

默认由模型判断,大致准确。想要 100% 准确:把考纲词表放进 `wordlists/` 文件夹
(一个文件一个标签,文件名即标签名,每行一个词),重新处理即可。词表优先于模型。

## 八、目录结构

```
process.py            主流程:视频 → data.json
demo.py               生成演示内容(不需要 key)
serve.py              本地服务(支持 Range 请求,视频才能拖动)
player.html           播放器(单文件)
teco/
  llm.py              DeepSeek/Kimi 统一客户端 + 缓存 + 用量统计
  asr.py              语音识别(词级时间戳)
  segment.py          语义群切分 + 翻译     ← 核心
  cards.py            知识点抽取 + 回原文校验 ← 核心
  ipa.py              IPA 音标(本机)
  meta.py             难度/语速/建议时长/主题
library/<期数>/       data.json + 视频 + 封面
wordlists/            可选:权威考纲词表
```

## 九、这套东西还能干别的

流水线的内核是「**把非结构化的音视频,变成结构化的、可检索的专业记录**」。
换掉 `cards.py` 里的抽取提示词和输出模板,同一套骨架可以做:
会议录音 → 纪要与待办、上门服务录音 → 工作记录、播客 → 笔记、课程 → 讲义。

英语学习只是它的第一个应用。
